# VaultNote

사이트별 아이디·비밀번호를 폴더 트리로 정리해 **내 폰 안에서만 암호화해 보관**하는 계정 수첩입니다.
서버가 없어서 내 데이터는 어디에도 전송되지 않습니다.

> **먼저 읽어 주세요**
> - 개인이 가족·지인과 나누려고 만든 앱입니다. 전문 보안 업체의 검증을 받지 않았고, **어떤 보증도 하지 않습니다**(아래 라이선스 참고).
> - **마스터 비밀번호를 잊으면 아무도 복구할 수 없습니다.** 만든 사람도 못 엽니다.
> - **백업 파일이 없으면 폰을 잃어버리거나 브라우저 데이터를 지울 때 모든 계정이 사라집니다.**
> - 금융·주 이메일 같은 아주 중요한 계정은 검증된 앱(KeePassDX 등)과 함께 쓰기를 권합니다.

## 지원 환경

| 환경 | 상태 |
| --- | --- |
| 안드로이드 + 크롬 | 시험 완료 |
| 안드로이드 + 삼성 인터넷 | 시험 안 함 (대부분 동작할 것으로 예상) |
| 아이폰 · 아이패드 | **시험 안 함.** 홈 화면에 설치하지 않으면 데이터가 지워질 수 있어 권하지 않습니다 |

## 설치하기 (처음 한 번, 약 20분)

각자 **자기 GitHub에 이 앱을 복사(fork)해서** 씁니다. 이렇게 하면 다른 사람의 계정에 문제가 생겨도 내 금고는 영향을 받지 않습니다.

1. **GitHub 계정 만들기:** 폰 크롬에서 `github.com/signup`에 가입합니다. 이 앱 전용으로 쓸 계정을 새로 만드는 것이 좋습니다.
2. **2단계 인증 켜기:** 프로필 사진 → Settings → Password and authentication → Enable two-factor authentication. 인증 앱(Google Authenticator 등)에 등록하고, **복구 코드는 종이에 적어 보관**합니다.
3. **복사(fork):** 이 저장소 페이지에서 **Fork** → **Create fork**를 누릅니다. 이름은 `vaultnote` 그대로 둡니다.
4. **웹 주소 켜기:** 내 저장소의 **Settings → Pages**에서 Branch를 **main**, 폴더를 **/(root)**로 고르고 **Save**를 누릅니다.
5. **접속:** 1~2분 뒤 `https://내아이디.github.io/vaultnote/`를 폰 크롬으로 엽니다. "금고 만들기" 화면이 나오면 성공입니다.
6. **홈 화면에 설치:** 한 번 새로고침한 뒤 크롬 메뉴(⋮) → **홈 화면에 추가**(또는 앱 설치)를 누릅니다.

> 이 GitHub 계정에는 다른 저장소나 웹페이지를 만들지 마세요. 같은 주소 아래의 다른 페이지가 금고 저장소에 접근할 수 있습니다.

## 처음 쓰기

1. **마스터 비밀번호 정하기:** 서로 관련 없는 단어 4~5개를 띄어 쓰면 기억하기 쉽고 강합니다(예시 문구를 그대로 쓰지는 마세요). **종이에 적어 안전한 곳에 보관**하세요.
2. **크롬이 비밀번호 저장을 물으면 "사용 안함"**을 누르세요.
3. 왼쪽 아래 버튼으로 폴더를, 오른쪽 아래 버튼으로 계정을 추가합니다.
4. **키보드 클립보드 기록 끄기:** 삼성 키보드·Gboard 설정에서 클립보드 기록을 끄세요. 복사한 비밀번호가 키보드에 남지 않게 합니다.

## 백업하기 (한 달에 한 번)

1. 설정(왼쪽 위 아이콘) → **암호화 백업 파일 만들기** → 다운로드 폴더에 `vault_날짜.vault`가 생깁니다.
2. 이어서 **지금 확인**을 눌러 방금 만든 파일을 열어 봅니다. "확인됐습니다"가 떠야 백업이 끝난 것입니다.
3. 그 파일을 **PC와 USB 등 폰 밖 두 곳**에 옮겨 둡니다. 클라우드·메신저에는 올리지 마세요.

## 폰을 바꿀 때

새 폰에서 내 주소를 열고 홈 화면에 설치한 뒤, "금고 만들기" 화면 아래의 **백업 파일로 복원하기**를 누르고 백업 파일과 마스터 비밀번호를 넣습니다.

## 업데이트 받기

만든 사람이 새 버전을 올렸다고 **직접(전화·문자로) 알려 줄 때만** 아래를 하세요.

1. 내 GitHub 저장소 페이지에서 **Sync fork** → **Update branch**를 누릅니다.
2. 5~10분 뒤 앱을 열면 "새 버전이 있습니다" 배너가 뜹니다. **먼저 백업 → 업데이트**를 누릅니다.

> 아무 연락도 없었는데 배너가 뜨면 **누르지 말고** 만든 사람에게 먼저 물어보세요.

## 자주 묻는 질문

- **마스터 비밀번호를 잊었어요.** 복구할 방법이 없습니다. 새 금고를 만들고 계정을 다시 입력해야 합니다.
- **5번 틀려서 막혔어요.** 30초 뒤 다시 시도하세요.
- **다른 앱에 다녀오니 잠겨 있어요.** 정상입니다. 설정 → 보안에서 잠기는 시간을 바꿀 수 있습니다.
- **실수로 지웠어요.** 지운 직후 5초 안에는 "실행 취소", 그 뒤에는 설정 → **저장본 기록에서 되돌리기**를 쓰세요.
- **가족과 금고를 함께 쓸 수 있나요?** 아니요. 금고는 각자 폰에 따로 있습니다.

## 보안에 대해

- 비밀번호는 PBKDF2(60만 회)로 만든 키와 AES-256-GCM으로 암호화되어 이 기기에만 저장됩니다.
- **이 앱이 막지 못하는 것:** 잠금이 풀린 화면을 다른 사람이 보는 것, 악성 앱이 깔리거나 루팅된 폰, 내 GitHub 계정이 해킹되는 것, 약한 마스터 비밀번호로 만든 백업 파일이 새어 나가는 것.
- 문제를 발견하면 만든 사람에게 직접 알려 주세요.
